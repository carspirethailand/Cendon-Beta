ข้อตกลงรักษาความลับ

คู่มือระบบมีรายละเอียดโครงสร้างภายในทั้งหมดของ Cendon
อ่านข้อกำหนดให้จบแล้วลงลายมือชื่อ เพื่อเข้าดูเนื้อหา

ข้อตกลงฉบับนี้ทำขึ้นระหว่าง บริษัท Phasmion ผู้เป็นเจ้าของระบบ Cendon กับผู้ลงลายมือชื่อท้ายเอกสารนี้ โดยมีผลนับตั้งแต่วินาทีที่ลงลายมือชื่อเป็นต้นไป

1. สิ่งที่ถือเป็นความลับ

ทุกสิ่งที่ปรากฏในคู่มือระบบถือเป็นความลับทางการค้าของบริษัท ครอบคลุมถึง

  1. โครงสร้างฐานข้อมูล ชื่อตาราง ชื่อคอลัมน์ และความสัมพันธ์ระหว่างตาราง
  2. ที่อยู่และการตั้งค่าของเซิร์ฟเวอร์ ผู้ให้บริการ และบริการภายนอกที่ระบบใช้
  3. รายการเส้นทาง API ทั้งหมด รวมถึงรูปแบบข้อมูลที่รับและส่ง
  4. กลไกการยืนยันตัวตน การกำหนดสิทธิ์ และการคิดโควตา
  5. สถาปัตยกรรมของระบบค้นด้วยความหมาย และค่าที่ใช้ปรับจูน
  6. รายการช่องโหว่ ข้อบกพร่อง และสิ่งที่ยังไม่เรียบร้อยซึ่งบันทึกไว้ในคู่มือ
  7. วิธีการทำงาน ขั้นตอนภายใน และการตัดสินใจเชิงเทคนิคที่อธิบายไว้

2. สิ่งที่ห้ามทำ

  1. ห้ามเปิดเผย เนื้อหาไม่ว่าทั้งหมดหรือบางส่วน แก่บุคคลที่ไม่มียศผู้ควบคุมขึ้นไปในระบบนี้ ไม่ว่าด้วยวาจา ข้อความ ภาพถ่ายหน้าจอ การบันทึกหน้าจอ หรือวิธีอื่นใด
  2. ห้ามคัดลอก ทำซ้ำ ดัดแปลง แปล หรือสรุปเนื้อหา ไปเก็บไว้นอกระบบนี้ รวมถึงในเครื่องส่วนตัว บริการเก็บไฟล์ออนไลน์ แอปจดบันทึก และเครื่องมือ AI ภายนอกทุกชนิด
  3. ห้ามนำไปใช้ เพื่อประโยชน์ของตนเองหรือผู้อื่น นอกเหนือจากการปฏิบัติงานให้บริษัท รวมถึงการนำไปสร้างระบบที่แข่งขันกัน
  4. ห้ามพยายามเข้าถึง ด้วยวิธีอื่นนอกจากผ่านหน้านี้ เช่นการเรียกเส้นทาง API โดยตรง การดักจับข้อมูล หรือการใช้บัญชีของผู้อื่น
  5. ห้ามแบ่งปันบัญชีของตนให้ผู้อื่นใช้ และห้ามเปิดหน้านี้ค้างไว้ ในที่ที่ผู้อื่นมองเห็นได้

3. หน้าที่ในการดูแลรักษา

  1. ใช้ความระมัดระวังในการรักษาความลับนี้ไม่น้อยกว่าที่ใช้กับความลับของตนเอง
  2. เข้าดูเฉพาะเมื่อมีความจำเป็นต่อการทำงาน ไม่เปิดดูเพื่อความอยากรู้
  3. แจ้งบริษัททันทีเมื่อทราบว่ามีการรั่วไหล การเข้าถึงโดยไม่ได้รับอนุญาต หรือสงสัยว่าบัญชีของตนถูกผู้อื่นใช้
  4. เมื่อพ้นจากหน้าที่ ต้องหยุดเข้าดูทันที และทำลายสำเนาทุกรูปแบบที่มีอยู่

4. การบันทึกและการตรวจสอบ

บริษัทบันทึกการเข้าดูคู่มือทุกครั้ง พร้อมบัญชีผู้เข้าดูและเวลา และแสดงชื่อกับอีเมลของผู้อ่านเป็นลายน้ำบนหน้าจอตลอดเวลาที่เปิดอ่าน หากเนื้อหารั่วไหล บริษัทสามารถระบุได้ว่าหลุดจากบัญชีใด

5. ระยะเวลา

หน้าที่รักษาความลับตามข้อตกลงนี้ไม่มีกำหนดสิ้นสุด และยังคงมีผลต่อไปแม้ผู้ลงลายมือชื่อจะพ้นจากตำแหน่ง สิ้นสุดสัญญาจ้าง หรือถูกถอนสิทธิ์เข้าถึงระบบไปแล้วก็ตาม

6. ผลของการฝ่าฝืน

การฝ่าฝืนข้อตกลงนี้เป็นการละเมิดความลับทางการค้า บริษัทมีสิทธิ์ระงับการเข้าถึงระบบทันทีโดยไม่ต้องบอกกล่าวล่วงหน้า เรียกค่าเสียหายตามความเสียหายที่เกิดขึ้นจริง และดำเนินคดีตามกฎหมายทั้งทางแพ่งและทางอาญา

7. การยอมรับ

การลงลายมือชื่อในหน้านี้ถือว่าผู้ลงลายมือชื่อได้อ่าน เข้าใจ และตกลงผูกพันตามข้อกำหนดทั้งหมดข้างต้นด้วยความสมัครใจ ลายมือชื่อที่วาดในหน้านี้ พร้อมบัญชี เวลา และอุปกรณ์ที่ใช้ จะถูกบันทึกไว้เป็นหลักฐาน
