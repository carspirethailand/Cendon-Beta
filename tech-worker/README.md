# spireone-techs — เซิร์ฟเวอร์ระบบช่าง Cendon Care

หน้า `techs.html` เรียกเซิร์ฟเวอร์ตัวนี้ที่
`https://spireone-techs.carspirethailand.workers.dev`
ถ้ายังไม่ deploy หน้าช่างจะขึ้นว่า "ยังโหลดรายชื่อไม่ได้" และทำอะไรต่อไม่ได้

แยกจาก `spireonebackend` โดยตั้งใจ เพราะใบงานเก็บเบอร์และที่อยู่ลูกค้า
ฐานข้อมูลคนละก้อน ถ้าฝั่งไหนมีปัญหา อีกฝั่งยังอยู่ครบ
และไม่ต้องแก้โค้ดของระบบหลักเลย

## ขึ้นเซิร์ฟเวอร์ครั้งแรก

```bash
cd tech-worker
npm install
npx wrangler login
npx wrangler d1 create spireone-techs
# เอาเลข database_id ที่ได้ ไปใส่แทน REPLACE_WITH_ID_FROM_d1_create ใน wrangler.jsonc
npm run db:remote     # สร้างตาราง
npm run deploy
```

ครั้งต่อไปแก้โค้ดแล้วรัน `npm run deploy` อย่างเดียว

## ผู้ดูแล

อีเมลใน `OWNERS` ของ `wrangler.jsonc` คือผู้ดูแลระบบช่าง
- ตรวจใบสมัคร อนุมัติได้เมื่อติ๊กครบทั้ง 6 ด่านเท่านั้น
- พักช่างออกจากรายชื่อ
- **สร้างช่างทดสอบด้วยชื่ออย่างเดียว** ข้ามเกณฑ์ทั้งหมด
  ช่างทดสอบไม่โผล่ในรายชื่อสาธารณะ รีวิวไม่ถูกนับ
  ผู้ดูแลจองช่างทดสอบของตัวเองได้ แล้วสลับพิมพ์แชตเป็นลูกค้าหรือช่างได้ในบัญชีเดียว

## รันในเครื่อง

```bash
npm run db:local
npm run dev          # เปิด DEV_AUTH ให้ใช้โทเคน dev:<uid>:<email> แทน Firebase
```

`DEV_AUTH` ไม่มีใน `wrangler.jsonc` บนเซิร์ฟเวอร์จริงจึงไม่มีทางลัดนี้

## ขั้นตอนของใบงาน

```
requested → quoted → accepted → (enroute) → working → done → completed → review
    └─ cancel ได้ก่อนเริ่มซ่อม      dispute ได้ตั้งแต่ยืนยันราคา → ผู้ดูแล resolve
```

- ช่างเห็นที่อยู่และเบอร์ลูกค้า **หลังลูกค้ายืนยันราคาแล้วเท่านั้น**
- ก่อนยืนยัน เบอร์โทรและไลน์ที่พิมพ์ในแชตจะถูกซ่อน หลังยืนยันแล้วไม่ซ่อนอะไรเลย
- คะแนนและจำนวนงานของช่างมาจากงานที่ปิดจริงเท่านั้น ช่างใหม่เริ่มที่ 0 ไม่ใช่ 5 ดาว

## ยังไม่มี

- รับชำระเงิน / เงินพักไว้ — หน้าเว็บบอกผู้ใช้ตรง ๆ ว่ายังไม่มี
- แจ้งเตือนทาง SMS หรือ push — ตอนนี้ใช้ตัวเลขบนปุ่ม "งานของฉัน" ที่อัปเดตทุกนาที
- แนบรูปในแชต
